# Service-level objectives

- Status: Not applicable
- Owner: @rokogan
- Review cadence: When the app is shared beyond the owner

This is a personal desktop tool with one user and no service to monitor, so there are no SLOs, dashboards, or alerts.

The behavior targets live in the [product brief](../product/brief.md): the TV changes within 3 s of play or pause, and the desktop is never left at movie brightness. They are checked by the unit tests and the live checks in [testing](../testing.md). Failures show up in the tray tooltip and the log.
