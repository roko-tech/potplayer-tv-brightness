# User documentation

Replace this page with task-oriented documentation before the first user release.

## Required structure

- **Quick start:** prerequisites, installation/access, first successful outcome, and expected result.
- **How-to guides:** the important user goals, including failure/recovery paths.
- **Reference:** configuration, commands, API/fields, limits, permissions, and compatibility.
- **Explanation:** concepts users need to make safe choices.
- **Troubleshooting:** symptom, likely cause, safe diagnosis, remedy, and escalation route.
- **Privacy/security:** collected data, permissions, retention/deletion, and vulnerability/support contact.
- **Known limitations:** unsupported platforms, scale, formats, integrations, and irreversible operations.

Write from the released artifact and verify instructions in a clean supported environment. Screenshots must match the current UI and avoid real personal or secret data.
